# Lotería Draw Tracker

A static, mobile-ready Lotería draw tracking app. It stores all data in the browser's localStorage and requires no backend.

## Deploy to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then save.

## Features

- Record cards in exact draw order
- Prevent duplicate cards within a game
- Edit or delete saved games
- Top five most frequently drawn cards
- Most common first and last cards
- Average draw position by card
- Complete sortable card statistics
- JSON backup export and import
- Corruption-safe validation and versioned storage
- Full local data reset
- Responsive light/dark interface
